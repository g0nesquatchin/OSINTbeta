What SpiderFoot does

SpiderFoot is an open-source OSINT automation tool. Give it a target — domain, IP, email, name, username, phone — and it queries up to ~200 data sources to enrich it. Each "scan" is one investigation, and results are organized by event type (subdomains, related accounts, breaches, etc.).
